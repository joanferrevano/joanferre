El proyecto

BatoiLOGIC es una empresa ficticia de distribución logística comarcal que necesitaba digitalizar todos sus procesos.

El proyecto consiste en desarrollar un ecosistema completo: dos apps móviles Flutter, una API REST con Spring Boot desplegada en AWS EC2, un backoffice Windows Forms en C#, un backoffice Odoo con módulos personalizados y una app CLI de importación/exportación de datos.

Aplicaciones

Cinco piezas que forman un ecosistema

  • App Repartidores

    App móvil para repartidores con gestión de rutas, geolocalización GPS en tiempo real, actualización de estados de entrega y comunicación vía WebSocket con el backoffice.

    Flutter · Dart · SQLite · WebSocket

  • App Clientes

    App móvil para clientes con registro, creación de pedidos y seguimiento en tiempo real del estado de cada entrega.

    Flutter · Dart · SQLite

  • Backoffice Windows

    Aplicación de escritorio para gestión de pedidos, rutas y seguimiento de flota en tiempo real. Incluye reconocimiento de voz para control por comandos.

    C# · Windows Forms · WebSocket

  • Backoffice Odoo

    Módulos personalizados de repartidores y camiones, albaranes, facturas y gestión de stock integrados directamente en el ERP.

    Python · Odoo · PostgreSQL

  • App CLI

    Herramienta de línea de comandos para importación y exportación masiva de ciudades, códigos postales, tarifas y rutas al sistema.

    Java

Mi contribución

  • Arquitectura

    Diseño de la arquitectura del sistema y modelo de datos relacional que soporta el ecosistema completo de cinco aplicaciones.

  • Backend

    Desarrollo de la API REST completa con Spring Boot, Hibernate y documentación de endpoints para consumo desde todas las apps.

    Desarrollo de las dos apps móviles Flutter — cliente y repartidor — con geolocalización en tiempo real, estados de pedido y persistencia local SQLite.

    Configuración de Odoo con módulos personalizados de repartidores y camiones, integración de albaranes y gestión de stock adaptada al flujo logístico.
